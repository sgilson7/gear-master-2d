# SECOND-ORDER-M13.md — the notebook

Kept as the block runs. One row a consequence that the plan did not ask for
and that the work made true anyway. The last milestone reads this file, turns
what is left into milestones, and executes them — which is why a row here is
written *when it is noticed* rather than at the end, when it would be a
reconstruction.

**What goes in.** A thing that became true because something else was built.
Not a bug (that is a fix), not a task (that is the plan). A second-order
effect is a sentence of the form *"now that X, Y is different"*.

**Columns.** `#`, where it came from, what is now true, and **what it wants** —
which is the column the last milestone reads.
